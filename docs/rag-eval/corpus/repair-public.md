# 教室与公共区域报修办理指南

服务编码：REPAIR-PUBLIC　｜　责任部门：资产管理处　｜　生效日期：2025-09-01

## 适用范围

**教学楼、实验楼、图书馆、自习区、走廊、公共卫生间**等公共区域的设施故障，包括桌椅损坏、多媒体设备、照明电路、门窗损坏等。

学生宿舍内部故障请走「宿舍报修」（REPAIR-DORM），不要在此提交。

## 申请方式

通过 Student Hub 小程序 → 服务大厅 → 教室与公共区域报修提交，需填写：

- 联系方式
- 报修地址（如「教学楼 A 栋 302 教室」）
- 故障类型（桌椅损坏 / 多媒体设备 / 照明电路 / 门窗损坏 / 其他）
- 问题描述
- 故障照片（选填，最多 3 张）

## 响应时效

受理后 **5 个工作日**内安排处理。因涉及公共教学资源，寒暑假期间仅处理安全隐患类故障，非紧急报修顺延至开学后。

时效比宿舍报修长，原因是公共区域故障需先由资产管理处统一排期、避开上课时段。

## 处理流程

同样启用拍照确认闭环：

1. 调度派单 → 维修人员接单
2. 上传**现场照片**
3. 上传**完工照片**并填写办理结果说明
4. 报修人确认完成，或退回重新处理

## 常见问题

**问：多媒体设备坏了影响上课怎么办？**
请联系教务处教室管理科 0571-8888-6203 现场应急，同时在系统补录报修单。

**问：可以匿名报修吗？**
不可以，需登录本人账号以便维修人员联系确认。

**问：假期报修会有人处理吗？**
暑假（7 月 15 日—8 月 25 日）与寒假期间仅受理安全隐患类，其余顺延。
