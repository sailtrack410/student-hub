# 宿舍报修办理指南

服务编码：REPAIR-DORM　｜　责任部门：后勤保障处　｜　生效日期：2025-09-01

## 适用范围

本校在读学生本人居住的**学生宿舍**内设施故障，包括水电、家具、门窗、网络端口等。

教学楼教室、自习区、走廊、公共卫生间等**非宿舍区域**请走「教室与公共区域报修」（REPAIR-PUBLIC），两者受理部门和时效不同。

## 申请方式

通过 Student Hub 小程序 → 服务大厅 → 宿舍报修提交，需填写：

- 联系方式（手机号）
- 报修地址（校区 + 楼栋 + 房间号，如「东校区 3 栋 412」）
- 故障类型（水电维修 / 家具维修 / 门窗维修 / 网络故障 / 其他）
- 问题描述
- 故障照片（选填，最多 3 张）

## 响应时效

受理后 **3 个工作日**内安排维修人员联系上门。涉及水管爆裂、漏电等紧急情况不受此限，请同时拨打后勤值班电话 0571-8888-6120。

## 处理流程

本类工单启用**拍照确认闭环**，必须按顺序完成，不能直接办结：

1. 调度派单 → 维修人员接单
2. 维修人员到达现场后上传**现场照片**
3. 维修完成后上传**完工照片**并填写办理结果说明
4. 报修人在小程序确认完成

报修人若认为未修好，可点击「需要继续处理」退回，维修人员需重新上传完工照片。

## 常见问题

**问：可以指定上门时间吗？**
申请表中「期望上门日期」为意向登记，实际以维修人员电话约定为准。

**问：周末能上门吗？**
可以，周末维修值班照常，但紧急程度低于工作日。

**问：维修要收费吗？**
正常使用造成的损坏免费维修；人为损坏、私自改装造成的故障按维修成本收费。
