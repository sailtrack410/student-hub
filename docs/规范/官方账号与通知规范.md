## 官方通知抓取

- 分区：`OFFICIAL_NOTICE`「校园通知」（V60 新增，ID 6005）。
- 来源配置：`official_feed_source`，种子为学校官网「通知公告」「奖助政策」「收费公示」三个栏目。
- 抓取记录：`official_feed_article`，`source_url` 唯一，内容哈希用于跨 URL 去重。
- 仅允许 `mycc.edu.cn` 及其子域；重定向后再次校验。
- 单次最多处理 `max_articles` 篇新文章；超过 `max_age_days` 的旧通知记录为 SKIPPED，不发布。
- 正文含图片 → ARTICLE（图片先经文件服务压缩入库，正文块按原文顺序保存）；纯文本 → DYNAMIC。
- 正文为空时回退提取内嵌 PDF 或附件链接；解析失败记录 FAILED，下次同步会重试。
- 默认每 30 分钟定时同步（`studenthub.official-feed.interval-ms`，首次延迟 `initial-delay-ms`），管理端「社区 → 官方通知」可手动同步单个/全部来源。

## 管理端

- 路由：`#/community-official`，组件 `OfficialFeedPage`。
- 能力：来源增改、启用/停用、单源同步、全部同步、抓取记录（已发布/已跳过/失败）分页查看。
- 帖子发布后可在「帖子管理」按分区「校园通知」查看，帖子详情中的作者会带官方标识。
