# 管理端科技蓝高密度视觉改版

> 状态：已交付 ｜ 日期：2026-10-20 ｜ 范围：`src/main/resources/static/admin/**`
> 触发反馈：管理端「社区概览」信息过薄、横向大面积留白（实测页面内容仅 505.5px 宽），方向为「现代点、科技蓝、不要渐变、信息密度要大」。
> 关联规范：[管理端视觉设计规范](../设计/管理端视觉设计规范.md)（第三版）

## 一、目标与验收口径

1. 主色由青绿改为科技蓝，**全站不出现颜色渐变**；
2. 壳层收紧，数据面满宽，不再出现居中窄列；
3. 社区概览形成 6 KPI + 趋势/处置 + 分区/健康四块数据面；
4. 桌面 1904/1440 与 1024 响应式均可用；
5. 30 条管理端路由巡检无控制台错误。

## 二、实现内容

### 2.1 Token 与主题

`css/campus-os.css` 重写亮/暗 token：

| 语义 | Light | Dark |
|---|---|---|
| 工作区底 | `#F2F5FA` | `#080E1A` |
| 面板 | `#FFFFFF` | `#0F172A` |
| 品牌/主操作 | `#2563EB` | `#3B82F6` |
| 品牌 hover | `#1D4ED8` | `#60A5FA` |
| 分隔线 | `#E3E8F2` | `#22304D` |
| 主文字 | `#0B1526` | `#E8EEF9` |
| 导航栏 | `#070D1A` | `#070D1A` |

- 面板圆角统一 6px，按钮/输入/页签 4px，弹层 8px；页面元素只用 1px 边框，不用装饰阴影；
- 移除 `linear-gradient`/`radial-gradient`/`conic-gradient`/`mask-image` 共 16 处，包括登录页背景、品牌 mark、当前导航、头像、趋势面积填充、广告缩略图和工单环形图；
- 工单环形图改为 SVG `stroke-dasharray` 分段，不再用 `conic-gradient`。

### 2.2 壳层密度

| 部位 | 改版前 | 改版后 |
|---|---|---|
| 顶栏 | 76px | 56px |
| 侧栏 | 248px | 212px（1280 以下保持完整文字菜单） |
| 内容边距 | 24/28px | 16px 20px 20px |
| 导航项 | 38px | 30px（分组标题 30px） |
| 页面区块间距 | 16–20px | 12px（总览 10px） |
| 页面最大宽 | 1560px 且会收缩 | 1600px，`width:100%; align-self:stretch` |

关键修复：原 `.content > .pgw` 在 flex 列中按内容收缩，1904 视口实测仅 505.5px 宽；现改为满宽，并将 `max-width` 提升至 1600px。

导航改为按分类折叠的菜单：默认全部收起，仅保留分类名、条目数和展开箭头；点击分类展开/收起，展开状态写入 `localStorage`；当前路由所在分类在收起时以浅蓝底标识。1280 以下仍然保持 212px 完整文字菜单，不再切换为图标栏；1024 以下才切换为抽屉。

### 2.3 社区概览重排

`js/pages/community-ops.js` 的 `overview` 页签重写为：

- 顶部工具条：当前校区 / 近 7 天 / 更新时间 / 刷新；
- 6 列 KPI：帖子总数、评论总数、7 日活跃用户、待处理举报、待处理申诉、隐藏内容；
- 主区 2.1fr + 1fr：近 7 天发帖柱状图（含峰值/日均/今日）＋ 处置队列（3 条并可跳转）；
- 次区 2.1fr + 1fr：分区结构表（帖子/占比/分布）＋ 内容健康（由隐藏内容占比估算）；
- KPI 与队列均保留真实接口 `/api/admin/community/overview`，未新增假数据；空态显示加载或 0；
- 同时修复帖子/申诉/话题/屏蔽词页签通过深链接首次进入不加载数据的既有缺陷（初始化时按当前页签拉取对应接口）。

### 2.4 响应式

- ≥1181px：6 KPI 单行，主/次区双栏，页面高度铺满；
- ≤1180px：KPI 3 列，双栏改单栏，页面自然滚动；
- ≤1280px：侧栏保持 212px 完整文字菜单，分类折叠状态不变；
- ≤1024px：侧栏变抽屉，顶栏两行自适应，内容 12px 边距；
- 移除了原有的 88px 图标栏断点，避免窄桌面把菜单收成纯图标。

### 2.5 AI 基座四页签重做

反馈中的 `/admin/#/ai` 只渲染页签、内容区空白，根因是页签组件以字符串返回，子页只注册在 `window.AdminPages` 未注册为 Vue 组件。修复后四个页签全部落地为真实的「供应商—模型—默认路由—测试」控制面（`js/pages/aiconfig.js`、`js/pages/aitest.js`），并统一使用 `.ax-*` 高密度样式：

- **模型配置**：左侧供应商列表（筛选、启停状态、模型数、启用数）＋右侧供应商 Hero（Base URL、凭据、模型数、上次检查、检查结果、启停）＋模型表（类型、能力、上下文、最大输出、启用、编辑/删除）；下方补「能力覆盖 / 接入检查 / 路由规则」三块概览，用真实模型类型统计 6 类能力，空能力显示 0，不造假数据；
- **模型列表**：跨供应商汇总条、供应商/类型/关键词筛选、密集表格、编辑弹层；底部补类型分布 / 供应商分布 / 操作提示三块，用当前数据集实时计算；支持从供应商页带关键词深链进入并只显示匹配模型（请求序号 `loadSeq` 防止竞态覆盖）；
- **默认模型**：6 类默认（CHAT / VISION / ASR / TTS / EMBEDDING / RERANK）按能力选择，**只列出已启用供应商下的已启用模型**；右侧全局开关、超时、限流、上下文预算、摘要策略分组保存；默认模型变更与全局设置分别即时生效；
- **测试**：真实 SSE `/api/admin/ai/chat-stream`，chat 面板 + 右侧「测试目标 / 运行信息 / 快捷测试」；收到 `done` 后不再把浏览器 chunked 关闭误报为网络错误；出错显示错误态，不伪造成功；
- **暗色适配**：AI 页表格、气泡、输入区、概览卡按 Dark token 适配，控制面 Dark 下可读；≤1280 收起底部概览，≤1024 供应商改为上下布局并允许页面滚动；
- **真实接口**：全部走 `/api/admin/ai/providers|models|defaults|config|chat-stream`，无新增 mock 数据；远程模型导入按模型 ID 推断类型（RERANK / EMBEDDING / ASR / TTS / VISION / CHAT），不再全部默认成 CHAT。

同时修复一处 SSE 后端缺陷：异步完成后的 `ASYNC` 分派会再次进入 `AdminCampusContextInterceptor`，异步线程没有 `SecurityContext`，导致已完成的 SSE 被错误页覆盖、浏览器报 `ERR_INCOMPLETE_CHUNKED_ENCODING`。拦截器现只处理 `DispatcherType.REQUEST`，完成后 curl 退出码为 0、事件流正常收尾；接口协议未变。



### 2.6 统一布局、间距、字号与 UI 规范收口

在科技蓝方向基础上新增 `css/design-system.css`（约 500 行，加载在 `campus-os.css` 之后），把散落在页面里的字号、间距、控件高度、圆角收敛为一套 token：

| 项 | 统一值 |
|---|---|
| 侧栏 / 顶栏 | 212px / 56px；桌面完整文字菜单，分类手风琴默认收起 |
| 内容区 | `16px 20px 20px`；≤1024 为 12px；页面最大宽 1600px |
| 页面区块间距 | 12px；总览 10px，5 个区块在 1440/1904 完整露出 |
| 字号 | 10 / 11 / 12 / 13 / 14 / 16 / 20 / 24；页面标题 16px，表头 10px，表格 12px |
| 控件 | 按钮、输入、页签统一 30px 高、4px 圆角、12px 字号 |
| 表格 | 表头 10px/600，正文 12px，行高 38px 起 |
| 圆角 | 标签 3 / 控件 4 / 面板 6 / 弹层 8 |
| 标签/弹层 | 标签统一 20px 高；弹层统一 8px 圆角、20px 内边距 |

同时完成：

- 顶部路由 subtitle 补齐并统一（30 条路由均有上下文副标题，来自 `core/router.js` 的 `ROUTE_SUBTITLES`）；
- 系统配置页签从蓝色下划线改为统一填充式页签；社区/申诉页签的 32px、7px 圆角覆盖被归一；
- 清理 12 处页面内联高度覆盖、15 处非法 `10pxpx` 字体简写，补上 `--tk-mono`；
- 总览压缩 KPI/图表/底部区块，修复运行状态区块被 flex 压成 2–23px 的问题；≤840px 短屏允许总览纵向滚动，不再挤压底部区块；
- AI 页弹层与其它页弹层统一 8px 圆角、20px 内边距；AI 底部概览在 ≤1280 收起、短屏隐藏，保证首屏不裁切。

本轮实测口径（1440×900、1904×941、1280×900、1024×900）：

- 30/30 路由加载通过，0 控制台错误；
- 全部页面 `documentElement.scrollWidth <= clientWidth`，无横向溢出；
- 页签采集 35 个，全部 30px 高 / 4px 圆角 / 12px 字号；按钮采集 21 个，全部 30px 高；
- KPI 卡统一 87px 高；30 条路由无小于 10px 的文字；
- 知识库/社区/系统配置/AI 的任务弹层均为 8px 圆角。
