# 成就勋章素材清单

> 用途：勋章素材的**交付清单与命名对照**，供前端取素材、设计核对与验收。
> 生成链：`gpt-image-2.5` 逐枚生成 → 抠白底为透明 → 统一规范画布 → 按章码命名。脚本与中间产物在 `outputs/badges/`，定稿素材拷入 Flutter App 的 `app/assets/images/badges/`（当前主入口）；小程序端如需展示徽章，再补 `student-hub-weapp/assets/badges/`。

## 一、外形与风格规范（19 枚统一）

| 项 | 规范 |
|---|---|
| 外形 | **正六边形**：上下两条边水平、左右各一个顶点，六边等长、内角 120° |
| 画布 | 统一 **256×256 透明 PNG**；六边形内接框 **240×240** 居中，四周留 8px 余量 |
| 边框 | 外轮廓 + **同心正六边形内圈**，双线；线宽统一 |
| 线条材质 | **金属线条**（亮色/暗色双色调，有冲压感）：外轮廓、内圈、中心图形轮廓、内部装饰线都用它 |
| 填充 | 线条之间为**纯色珐琅块**；禁止渐变、投影、3D 立体渲染 |
| 底纹 | 下半部**扇形放射线**（从下边缘向中心发散），同样用金属线条勾勒 |
| 画面内容 | 只有徽章本体；**不含文字、数字、字母、角标、小色块、外圈底座** |
| 未获得态 | **不单独出素材**：同一张图用 CSS 灰度渲染（`filter: grayscale(1)` + 降低透明度） |

**稀有度通过金属线条材质与珐琅底色深浅表达**：普通 = 银色线条；稀有 = 金色线条；史诗 = 金色线条 + 更深珐琅底；传说 = 金色线条 + 深红珐琅 + 最繁复装饰线。

## 四、前端接入

- 素材路径：Flutter `app/assets/images/badges/<文件名>`，文件名即 `badgeCode`（移除后端的 `icon` 字段假设——V42 表无 icon 列）。方案B（2026-10-19）起：内置 19 枚仍随包；管理端新增码通过 `POST /api/admin/achievements/badges/{id}/icon` 上传，catalog 字典下发 `iconUrl`，客户端下载缓存兜底。
- 未获得态：同一素材加 CSS 灰度 + 透明度，**不要另出素材**（保证形状与已获得态完全一致）。
- 勋章墙：**4 列网格**（每枚显示 96–120rpx），下方两行文字——第一行名称，第二行解锁条件或"yyyy.M.d 获得"。
- 稀有度底色块/角标：**不占用素材**，如需在墙面上区分稀有度，用**文字标签或边框色**由前端叠加。
