# 管理端外部集成配置说明

> 状态：现行（2026-10-20）。适用于 QQ、微信、邮箱 SMTP、教务 JW、高德 AMap、RAG 知识库与文件存储。
> 入口：管理端「系统管理 → 系统配置 → 运行配置」、「文件存储」页，以及「外部集成」页的统一连通性测试。

## 1. 配置来源与优先级

1. 数据库 `sys_config` 显式值（管理员保存过，`updated_by != 0`）；
2. 启动时从环境变量迁移的种子值（只在空白、从未编辑过的行上执行一次）；
3. 未配置。管理员显式清空后的行不会回退环境变量。

敏感项（QQ APP KEY、微信 AppSecret、SMTP 密码、教务会话密钥、高德 Web 服务 Key、RAG PostgreSQL 密码、
文件签名密钥、MinIO AccessKey/SecretKey、OSS AccessKeyId/AccessKeySecret）使用 AES-256-GCM 加密写入
`sys_config`，页面和 API 只返回“已配置”，不回显明文；审计日志记录 `******`。
主密钥为环境变量 `CONFIG_SECRET_KEY`（至少 16 字符），不得提交到 Git。

## 2. 配置分组

| 分组 | 配置项 |
|---|---|
| QQ 登录 | 模式、APP ID、APP KEY、API 地址、默认校区、连接/读取超时 |
| 微信登录 | 模式、AppID、AppSecret、API 地址、默认校区、连接/读取超时 |
| 邮箱 SMTP | 启用、主机/端口/账号/密码、发件人、SSL/STARTTLS、超时、dev 验证码开关 |
| 教务系统 JW | SSO/JW/CAS 地址、RSA 模数/指数、会话加密密钥、保活时长、连接/读取超时、认证限流 |
| 高德地图 | Web 服务 Key、API 地址、连接/读取超时 |
| RAG 知识库 | 启用开关、独立 PostgreSQL JDBC URL/用户名/密码、文档大小/解析上限、向量化批大小、词法/向量召回候选数、词法最小相似度、RRF 常数 |
| 文件存储 | 存储实现（local/MinIO/OSS）、本地目录、单文件上限、签名 TTL/密钥、MinIO Endpoint/公开地址/桶/AK/SK、OSS Endpoint/公开域名/桶/AK/SK |

AI 供应商、官网抓取源由各自管理页面维护，不在本配置分组内重复。文件存储也可在「文件存储」页直接编辑，
与配置中心共用同一批 `file.*` 配置项；两种入口保存后都会热更新。

## 3. 热更新

保存成功后通过事务提交事件重新绑定对应属性 Bean，无需重启：

- QQ/微信：OAuth 客户端与模式；
- 邮箱：`JavaMailSender` 与实际发信配置；
- 教务：`JwProperties`、SSO RSA 公钥、会话 AES 密钥；
- 高德：`AmapProperties`，每次调用读取最新 Key/地址/超时；
- RAG：`RagProperties`；仅当启用状态或 JDBC 连接信息变化时重建 PostgreSQL 连接池，并初始化向量表/索引；只调召回参数不会断开连接；
- 文件存储：`FileProperties`；`RoutingBinaryStorage` 在下一次读写时按最新 `storage` 在 local/MinIO/OSS 间切换，
  MinIO/OSS 客户端按 Endpoint/AK/SK/桶的配置指纹懒重建，大小上限、签名 TTL/HMAC 密钥也立即生效。

## 4. 连通性测试

- 外部集成页：每个集成卡片均有「测试」；
- 运行配置页：有对应测试能力的分组显示「测试本组」；
- 文件存储页：local / MinIO / OSS 各有独立「测试」按钮，使用各自已保存配置探测，
  结果显示存储类型、Endpoint/桶、是否为当前生效存储、耗时与脱敏详情；
  单独测试不会切换 `file.storage`，因此可以先验证 OSS 再决定是否启用；
- 测试结果只返回脱敏摘要：主机可达性、HTTP 探测、SMTP 真实连接、PostgreSQL 与向量表状态、存储桶/目录可写性；
- QQ/微信/邮箱/教务/高德/RAG/文件存储均不会因测试失败而被伪报为已配置。

## 5. RAG 嵌入模型锁定

嵌入模型不在 RAG 分组里选择，而是复用「AI 基座 → 默认模型 → 向量模型（EMBEDDING）」。

- 知识库还没有向量时，可自由选择/更换嵌入模型；
- 一旦 `ai_knowledge_chunk` 中存在向量分块，后端会锁定当前记录的 `embedding_model`：
  禁止更换、清除默认、停用模型、删除模型、停用或删除该模型所属供应商；
- 管理端默认模型页显示锁定原因，下拉框和清除按钮置灰；
- 需要更换时，先删除全部知识库文档（清空向量分块），锁定自动解除；
- RAG 停用或 PostgreSQL 暂不可达时无法读取向量锁定状态，此时不做阻断，默认模型页只提示“暂不检查”；
  恢复连接后下一次打开页面会重新锁定。重新启用 RAG 前应先确认默认嵌入模型与既有向量一致。

## 6. 环境变量

完整清单见项目根 `README.md`「管理端配置中心」章节。新增组使用：

```bash
JW_SSO_BASE_URL / JW_JW_BASE_URL / JW_CAS_SERVICE / JW_ENCRYPT_KEY
JW_SESSION_TTL_HOURS / JW_CONNECT_TIMEOUT_SECONDS / JW_READ_TIMEOUT_SECONDS
JW_AUTH_RATE_LIMIT_PER_MINUTE
AMAP_WEB_SERVICE_KEY / AMAP_BASE_URL / AMAP_CONNECT_TIMEOUT_SECONDS / AMAP_READ_TIMEOUT_SECONDS
RAG_ENABLED / RAG_DB_URL / RAG_DB_USERNAME / RAG_DB_PASSWORD
FILE_STORAGE / FILE_STORAGE_DIR / FILE_SIGN_SECRET / FILE_MAX_SIZE_MB / FILE_VIEW_TTL_MINUTES
MINIO_ENDPOINT / MINIO_PUBLIC_ENDPOINT / MINIO_BUCKET / MINIO_ACCESS_KEY / MINIO_SECRET_KEY
OSS_ENDPOINT / OSS_PUBLIC_ENDPOINT / OSS_BUCKET / OSS_ACCESS_KEY_ID / OSS_ACCESS_KEY_SECRET
```

首次启动会把非空环境变量迁移到对应空白种子行；之后以管理端数据库值为准。RSA 公钥默认值在代码中继承，
可在管理端单独覆盖；生产变更建议同步更新部署 Secret，防止数据库恢复后丢失配置。

## 7. 验证记录

- 后端测试：`AdminPlatformConfigIntegrationTest` 覆盖 JW/高德/RAG/文件存储分组种子、热更新、敏感值加密与非法值拒绝；
  `StorageProbeTest` 覆盖 OSS 缺凭据脱敏提示、签名回退与本地存储路由探测；
  `AiEmbeddingModelLockServiceTest` 覆盖有向量锁定、无向量解锁、RAG 停用不查询、数据库异常不阻断配置页；
- 实机：JW 主机、高德 Web 服务 Key、RAG PostgreSQL、文件存储本机目录四项「测试本组」均返回可达；
  文件存储页分别测试 local / MinIO / OSS：OSS 桶探测返回可达，MinIO 因测试环境未配置 AK/SK 返回未配置；
  当前生效存储仍为 local，未在未确认的情况下切换生产存储；
- 实机：存在 4 个向量分块时，清除/停用/删除 EMBEDDING 模型均返回 400，原模型保持不变；
- 管理端截图：RAG 配置分组、文件存储分组、分组测试结果、AI 默认模型锁定提示。
